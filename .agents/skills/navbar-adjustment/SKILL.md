# Navbar Adjustment Skill (`navbar-adjustment`)

This project implements the standards defined by `navbar-adjustment`:
- **Height & Spacing**: Desktop height balanced at 64px (`py-3` / `py-5`), with flexible navigation gap (`gap-1` to `gap-2`).
- **Sticky Positioning**: `sticky top-0 z-50` with glassmorphism backdrop (`bg-slate-950/80 backdrop-blur-md`).
- **Responsive Drawer**: Desktop navigation hidden below `md:` breakpoint; mobile toggle button triggers full-width backdrop drawer with aria-labels.
- **Brand Alignment**: Center/baseline flex alignment with logo mark and brand text (`flex items-center gap-3`).
