# Web Development Skill (`web-development`)

This project implements the standards defined by `web-development`:
- **UI & Iconography**: Uses clean Lucide React vector icons with 1.5px-2.0px stroke weight.
- **Typography & Hierarchy**: Configured with Google Fonts (Plus Jakarta Sans & Space Grotesk).
- **Navbar Layout**: Sticky layout with concise menu links, `whitespace-nowrap`, and hamburger drawer for mobile viewports (<768px).
- **Accessibility & SEO**: Explicit `id`, `name`, and `autoComplete` attributes on forms, single `<h1>` hierarchy, OpenGraph metadata, and CSP headers.
