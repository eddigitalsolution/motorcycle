# Apex Riders - Premium Superbike & Motorcycle Rental

This repository follows the global web application project standards, anti-AI-slop design system, Cloudflare Pages static hosting conventions, and React 19 + TypeScript architecture.

## Tech Stack

- **Framework**: React 19, TypeScript, Vite 8
- **Styling**: Tailwind CSS v4, Lucide React
- **Animations**: Framer Motion 12, GSAP
- **Hosting Target**: Cloudflare Pages (`pages_build_output_dir: "./dist"`)

## Key Commands

- `npm run dev`: Start local development server
- `npm run build`: Type-check and build for production
- `npm run lint`: Run oxlint audit
- `npm run preview`: Preview built production app locally
